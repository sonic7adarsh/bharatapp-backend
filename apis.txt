Sequential Integration Runbook (Local)
======================================

Defaults:
- BASE = http://localhost:8081
- TENANT = local
- After login/register, capture TOKEN from response and reuse.

Storefront Flow (Buyer)
1) Register
   curl -X POST "http://localhost:8081/api/storefront/auth/register" \
     -H "Content-Type: application/json" -H "X-Tenant-Domain: local" \
     -d '{"name":"SF User","email":"sf@example.com","password":"Pass123!"}'
   -> Capture: none (optional token if returned)

2) Login
   curl -X POST "http://localhost:8081/api/storefront/auth/login" \
     -H "Content-Type: application/json" -H "X-Tenant-Domain: local" \
     -d '{"email":"sf@example.com","password":"Pass123!"}'
   -> Capture: TOKEN = .token

3) Profile (verify auth)
   curl -X GET "http://localhost:8081/api/storefront/auth/profile" \
     -H "Authorization: Bearer ${TOKEN}" -H "X-Tenant-Domain: local"

4) List products (capture an item)
   curl -X GET "http://localhost:8081/api/storefront/products?search=&category=" \
     -H "X-Tenant-Domain: local"
   -> Capture: PRODUCT_ID = first .id, PRICE = first .price, NAME = first .name

5) Categories
   curl -X GET "http://localhost:8081/api/storefront/categories" \
     -H "X-Tenant-Domain: local"

Checkout (COD)
6) Checkout
   curl -X POST "http://localhost:8081/api/storefront/checkout" \
     -H "Content-Type: application/json" -H "Authorization: Bearer ${TOKEN}" -H "X-Tenant-Domain: local" \
     -d '{"items":[{"id":"'"${PRODUCT_ID}"'","name":"'"${NAME}"'","price":'"${PRICE}"',"quantity":1}],"totals":{"payable":'"${PRICE}"'},"paymentMethod":"cod","address":{"line1":"123","city":"BLR"}}'
   -> Capture: ORDER_ID = .order.id, REFERENCE = .reference

7) Orders list
   curl -X GET "http://localhost:8081/api/storefront/orders" \
     -H "Authorization: Bearer ${TOKEN}" -H "X-Tenant-Domain: local"

8) Order detail
   curl -X GET "http://localhost:8081/api/storefront/orders/${ORDER_ID}" \
     -H "Authorization: Bearer ${TOKEN}" -H "X-Tenant-Domain: local"

Payments (Optional Online)
9) Create payment order
   curl -X POST "http://localhost:8081/api/storefront/payments/create-order" \
     -H "Content-Type: application/json" -H "Authorization: Bearer ${TOKEN}" -H "X-Tenant-Domain: local" \
     -d '{"amount":1500,"currency":"INR"}'
   -> Capture: PAYMENT_ORDER_ID = .id

10) Verify payment (example values)
    curl -X POST "http://localhost:8081/api/storefront/payments/verify" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${TOKEN}" -H "X-Tenant-Domain: local" \
      -d '{"razorpay_order_id":"'"${PAYMENT_ORDER_ID}"'","razorpay_payment_id":"pay_demo","razorpay_signature":"sig_demo"}'

Legacy Storefront (/store)
11) Products (legacy)
    curl -X GET "http://localhost:8081/store/products?search=&category=" -H "X-Tenant-Domain: local"
    -> Capture: PRODUCT_ID_LEG = first .id

12) Categories (legacy)
    curl -X GET "http://localhost:8081/store/categories" -H "X-Tenant-Domain: local"

13) Checkout (legacy)
    curl -X POST "http://localhost:8081/store/checkout" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${TOKEN}" -H "X-Tenant-Domain: local" \
      -d '{"items":[{"id":"'"${PRODUCT_ID_LEG}"'","name":"Prod","price":100,"quantity":1}],"totals":{"payable":100},"paymentMethod":"cod","address":{"line1":"123","city":"BLR"}}'
    -> Capture: LEGACY_ORDER_ID = .order.id

Seller Flow
14) Seller register
    curl -X POST "http://localhost:8081/api/auth/seller/register" \
      -H "Content-Type: application/json" \
      -d '{"name":"Seller","email":"seller@example.com","password":"Pass123!"}'

15) Seller login
    curl -X POST "http://localhost:8081/api/auth/seller/login" \
      -H "Content-Type: application/json" \
      -d '{"email":"seller@example.com","password":"Pass123!"}'
    -> Capture: SELLER_TOKEN = .token

16) Create store
    curl -X POST "http://localhost:8081/api/seller/stores" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${SELLER_TOKEN}" \
      -d '{"name":"Smoke Store","city":"BLR","area":"MG Road","category":"General"}'
    -> Capture: STORE_ID = .id

17) Create product (seller)
    curl -X POST "http://localhost:8081/api/seller/stores/${STORE_ID}/products" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local" \
      -d '{"name":"Item","price":299,"category":"General","currency":"INR","description":"Desc","stock":10,"active":true}'
    -> Capture: PRODUCT_ID = .id

18) List products (seller)
    curl -X GET "http://localhost:8081/api/seller/stores/${STORE_ID}/products?search=&category=&active=true&page=0&limit=25" \
      -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local"

19) Update product
    curl -X PATCH "http://localhost:8081/api/seller/products/${PRODUCT_ID}" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local" \
      -d '{"price":349,"active":true}'

20) Adjust inventory
    curl -X PATCH "http://localhost:8081/api/seller/products/${PRODUCT_ID}/inventory" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local" \
      -d '{"stockDelta":5,"price":299}'

21) List orders (seller)
    curl -X GET "http://localhost:8081/api/seller/orders?storeId=${STORE_ID}&status=&from=&to=&page=0&limit=25" \
      -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local"
    -> Capture: ORDER_ID = first .id

22) Update order status (seller)
    curl -X PATCH "http://localhost:8081/api/seller/orders/${ORDER_ID}/status" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local" \
      -d '{"status":"shipped","notes":"Packed and ready"}'

23) Create refund (seller)
    curl -X POST "http://localhost:8081/api/seller/orders/${ORDER_ID}/refunds" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local" \
      -d '{"amount":100,"reason":"Customer returned item"}'

24) Analytics overview (seller)
    curl -X GET "http://localhost:8081/api/seller/analytics/overview?storeId=${STORE_ID}&from=&to=" \
      -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local"

25) Payouts (seller)
    curl -X GET "http://localhost:8081/api/seller/payouts" \
      -H "Authorization: Bearer ${SELLER_TOKEN}" -H "X-Tenant-Domain: local"

Platform Products
26) List platform products
    curl -X GET "http://localhost:8081/api/platform/products?search=&category="

27) Create platform product
    curl -X POST "http://localhost:8081/api/platform/products" \
      -H "Content-Type: application/json" -H "Authorization: Bearer ${SELLER_TOKEN}" \
      -d '{"name":"Platform Item","price":299,"description":"Desc","category":"General","storeId":"${STORE_ID}"}'

Notes
- Storefront routes require: X-Tenant-Domain: local; and Authorization after login.
- Checkout requires items as a JSON array of CartItem objects.
- Use the captured IDs (PRODUCT_ID, STORE_ID, ORDER_ID, PAYMENT_ORDER_ID) exactly in subsequent steps.

API Prompt Examples (cURL)
==========================

Use these examples to quickly test and integrate the backend with the current UI. Replace placeholders like `{{BASE}}`, `{{TOKEN}}`, and IDs as needed.

Common headers:
- `-H "Content-Type: application/json"`
- `-H "Authorization: Bearer {{TOKEN}}"` (when logged in)
- `-H "X-Tenant-Domain: {{TENANT}}"` for storefront APIs

Storefront Auth
- Register:
  curl -X POST "{{BASE}}/api/storefront/auth/register" -H "Content-Type: application/json" -H "X-Tenant-Domain: {{TENANT}}" -d '{"name":"Alice","email":"alice@example.com","password":"Pass123!"}'

- Login (email):
  curl -X POST "{{BASE}}/api/storefront/auth/login/email" -H "Content-Type: application/json" -H "X-Tenant-Domain: {{TENANT}}" -d '{"email":"alice@example.com","password":"Pass123!"}'

- Login (phone):
  curl -X POST "{{BASE}}/api/storefront/auth/login/phone" -H "Content-Type: application/json" -H "X-Tenant-Domain: {{TENANT}}" -d '{"phone":"+919999999999","password":"Pass123!"}'

 - Send OTP (phone):
   curl -X POST "{{BASE}}/api/storefront/auth/otp/send" -H "Content-Type: application/json" -H "X-Tenant-Domain: {{TENANT}}" -d '{"phone":"+919999999999"}'

 - Verify OTP:
   curl -X POST "{{BASE}}/api/storefront/auth/otp/verify" -H "Content-Type: application/json" -H "X-Tenant-Domain: {{TENANT}}" -d '{"phone":"+919999999999","otp":"123456"}'

 - Resend OTP:
   curl -X POST "{{BASE}}/api/storefront/auth/otp/resend" -H "Content-Type: application/json" -H "X-Tenant-Domain: {{TENANT}}" -d '{"phone":"+919999999999","otpId":"OTP_abc123"}'

- Profile:
  curl -X GET "{{BASE}}/api/storefront/auth/profile" -H "Authorization: Bearer {{TOKEN}}" -H "X-Tenant-Domain: {{TENANT}}"
